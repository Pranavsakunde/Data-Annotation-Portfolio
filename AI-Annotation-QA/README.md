# AI Data Annotation Quality Assurance (QA) & Reviewer Workflow

**Portfolio case study | Simulated training exercise | No client data used**

## Overview
A no-code case study showing how a reviewer audits image and video annotations against written guidelines, classifies defects, assigns severity, records decisions, provides corrective feedback, and escalates ambiguous cases.

## Deliverables
- QA handbook and review workflow
- Image/video review checklist
- Annotation error taxonomy and severity guidance
- Reviewer feedback guide
- Standard operating procedure (SOP)
- 30 simulated audit cases in CSV

## Workflow
Receive task → confirm guideline/version → inspect scope → log defects with evidence → classify severity → approve, return, or escalate → provide feedback → verify corrections → close the audit record.

## Limitations
All 30 cases are simulated practice examples, not client work or production audit results. No independent second reviewer participated, so no inter-rater agreement statistic is claimed. Real projects must follow their own approved guidelines and acceptance criteria.

## Portfolio summary
Built a no-code AI Data Annotation QA case study covering image and video review. Created checklists, an error taxonomy, severity guidance, 30 simulated audit cases, reviewer feedback templates, and an SOP. Demonstrates structured quality review, evidence-based decisions, and escalation of ambiguous cases.
